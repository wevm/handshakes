# handshakes [The OAuth client for workloads and CLIs]

The `handshakes` entry returns access tokens for an API. It exchanges the OIDC token of a platform (RFC 8693), or runs and refreshes a device grant (RFC 8628). It also exports the standard requests that the client sends, for custom flows.

```ts [example.ts]
import { Client } from 'handshakes'

// Exchanges the platform token in CI, or uses the stored grant on a device
const client = Client.create({ issuer: 'https://auth.example.com', scope: 'data:read' })

const response = await client.fetch('https://api.example.com/v1/items')
```

## Installation

:::code-group

```sh [pnpm]
# Installs the package with pnpm
pnpm add handshakes
```

```sh [npm]
# Installs the package with npm
npm install handshakes
```

```sh [bun]
# Installs the package with Bun
bun add handshakes
```

:::

:::note
The entry has no dependencies and imports no Node built-ins, so it runs in Node, Bun, Deno, and edge runtimes. File system code, such as the file store, lives in [`handshakes/node`](/api/node).
:::
